- 写作材料：77篇；001保留历史个人作文，002—016保留既有题目、写作指导或原创学习示例，017—077根据本地真题与答案资料整理题面、来源定位和学习提炼；均不等同于官方范文或个人作答
- 词汇与句型：按“翻译xxx／写作xxx”来源标识合并整理，相同条目通过跨文档链接复用
- 练习状态：保留真实记录；未完成的练习继续标为未完成

## 内容说明

- 参考译文和学习用润色作文只用于语言学习，不是官方标准答案。
- 同一内容可以有多种正确表达，学习时应结合语境判断词汇、时态和句式。
- 部分写作题目根据提供的试卷图片人工转录，发布版不包含原始试卷图片。
- 笔记采用增量方式维护，新增材料会继续合并到现有词汇、句型和问题记录中。

## 建议使用方式

1. 先根据题目独立完成翻译或作文。
2. 再查看学习参考版本，比较信息是否完整、语法是否准确、搭配是否自然。
3. 将实际出现的错误记录到对应章节，并在复习时重新造句或完成迁移练习。
