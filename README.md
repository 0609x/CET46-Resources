# 英语四六级备考资源（CET4 / CET6）

> 一套汇总整理的大学英语四六级（CET-4 / CET-6）历年真题与备考文档，覆盖 **四级 2014–2025**、**六级 2013–2025** 共 52 个考次，包含真题、答案解析、可打印 PDF、Word 版与听力音频。

## 📌 使用说明

- **打印刷题**：优先使用 `真题PDF` 下的「可复制可搜索」版本，排版清晰。
- **核对答案**：同一考次有 3 套卷，**听力素材相同、选项顺序不同**；阅读、作文、翻译每套独立。核对答案时**请按选项内容对照，不要只看 ABCD**。
- **听力资源**：整套听力可在线播放，视频合集见 [Bilibili](https://www.bilibili.com/video/BV1Zu411x7k4/)。
- **备考路线**：详见 `备考文档/一些建议.md`（⭐ 推荐先读）；翻译专项见 `历年翻译汇总.md`；作文见 `可用作文素材.md`；高频表达见 `可用词汇整理.md`。

### 四六级时间规律
- **6 月**：上半年（每年 6 月中旬）
- **12 月**：下半年（每年 12 月中旬）
- **7 月 / 9 月**：特殊年份因疫情安排的补考（2020.07、2020.09、2022.09、2023.03 等）
