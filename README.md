# CET46-Resources ｜ 英语四六级备考资源

> 一套汇总整理的大学英语四六级（CET-4 / CET-6）历年真题，覆盖 **四级 2014—2026（28 个考次）**、**六级 2013—2026（27 个考次）**，共 **55 个考次**。内含真题 PDF、真题 Word、答案解析与听力音频。

| 子目录 | 内容 |
|--------|------|
| `真题PDF` | 真题 PDF（可复制、可搜索、打印首选） |

| `答案解析` | 答案与解析（PDF / Word） |
| `听力音频` | 听力 MP3（若有） |

> 完整覆盖情况见 [index.md](index.md)。

## 📌 使用说明

- **打印刷题**：优先使用 `真题PDF` 下的「可复制可搜索」版本，排版清晰。
- **核对答案**：同一考次有 3 套卷，**听力素材相同、选项顺序不同**；阅读、作文、翻译每套独立。核对答案时**请按选项内容对照，不要只看 ABCD**。
- **听力资源**：部分考次音频较大（个别 >50MB），可在线试听或按需下载；整套听力在线版见 [Bilibili](https://www.bilibili.com/video/BV1Zu411x7k4/)。

### 四六级时间规律
- **6 月**：上半年（每年 6 月中旬）
- **12 月**：下半年（每年 12 月中旬）
- **7 月 / 9 月 / 3 月**：特殊年份安排的补考（2020.07、2020.09、2022.09、2023.03 等）
