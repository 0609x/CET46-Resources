# CET46-Resources｜英语四六级备考资源

本仓库整理大学英语四、六级历年真题与学习笔记。目前收录四级 2014—2026 年的 28 个考次、六级 2013—2026 年的 27 个考次，共 55 个考次。资料包括真题 PDF、真题 Word、答案解析、听力音频，以及持续整理的六级翻译与写作学习笔记。

> 最近更新：六级 2025.12、六级 2026.06 已收录真题、答案解析与听力音频；四级 2026.06 已收录 3 套真题 PDF 和一份[非官方参考答案校对版](四级真题/2026.06/答案解析/2026年6月四级参考答案（卷面对照校对版）.md)，暂未收录本考次听力音频。各考次的实际文件数见[完整真题索引](index.md)。

## 如何使用

### 做真题

选择考试级别 → 选择考试年月 → 查看试卷和已有听力 → 独立完成 → 确认套题与选项内容后对照答案复盘。

部分试卷会共用听力素材，套号与听力版本不一定一一对应。核对答案时应先确认所用试卷和选项内容，再核对答案字母。

部分考次音频较大，可以按需下载；整套听力在线版见 [Bilibili](https://www.bilibili.com/video/BV1Zu411x7k4/)。

### 学习写作

阅读题目 → 独立构思或写作 → 查看写作思路和来源资料 → 整理可迁移表达 → 完成迁移练习。

### 学习翻译

独立翻译 → 按信息单元对照 → 检查遗漏、逻辑和语法 → 学习表达 → 再次翻译。

## 资料状态与来源

- **已收录**：仓库中存在对应文件，不表示内容已经过官方认证或完整审校。
- **未收录**：当前仓库没有对应文件。
- **待核对**：文件的内容、套题匹配或清晰度仍需确认。
- **非官方参考**：仅用于学习和复盘，不应视为官方答案。

仓库可能存在缺页、识别错误、排版错误或答案版本差异，请优先依据官方发布的信息。项目性质、内容权利归属及下架流程见 [RIGHTS.md](RIGHTS.md)。

## 考试时间说明

- **6 月**：常规上半年考试；
- **12 月**：常规下半年考试；
- **7 月、9 月、3 月**：仓库收录的特殊年份考次，例如 2020.07、2020.09、2022.09 和 2023.03。
